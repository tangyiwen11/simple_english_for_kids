# 小小自然拼读

一本可以发声、可以反复点的自然拼读小词典，为一名 5 岁、中文母语、正在新加坡幼儿园接触英语的孩子制作。

## 当前功能

- 26 个英文字母，可从主页自由选择
- 每个字母 6 个常用词，配有图形提示、中文意思和离线发音
- 大写与小写并排对照，目标字母在单词中用颜色标出
- “听单词找图片”和“听声音找字母”两个无压力互动
- 根据已经听过的字母逐步开放简单拼读词
- 学习记录保存在当前设备的 LocalStorage
- 支持安装到 iPad 主屏幕，并通过 Service Worker 离线使用

## 产品原则

- 唯一目标用户是自己的孩子
- 鼓励听、尝试和反复玩，不制造输赢压力
- 不做登录、排行榜、金币、签到、广告、商城或聊天
- 一次交互保持短小，不堆叠长篇讲解和固定视频
- 所有学习内容均可自由选择，不通过考试或家长操作解锁

## 本地运行

需要 Node.js 22 或更高版本。

```bash
npm install
npm run dev
```

正式构建与检查：

```bash
npm run build
npm test
```

## 音频

固定音频位于 `public/audio/`，网页不依赖在线语音服务。单词音频和字母纯音可以在 macOS 上重新生成：

```bash
zsh scripts/generate-audio.sh
```

脚本需要系统的 `say` 命令和 `/opt/homebrew/bin/ffmpeg`。字母纯音从示例单词中截取，避免合成语音把字母名称或控制指令读出来。
